# FINMATE Frontend

An aesthetic, modern financial dashboard built with Astro, React, and Framer Motion.

## Tech Stack
- **Framework**: [Astro](https://astro.build/)
- **UI Components**: [React](https://reactjs.org/)
- **Styling**: Vanilla CSS (Financial Noir theme)
- **Authentication**: [Supabase](https://supabase.com/)
- **Visualizations**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

1. **Install dependencies**:
   ```bash
   pnpm install
   ```

2. **Configure environment variables**:
   Copy `.env.example` to `.env` and fill in your Supabase credentials.
   ```bash
   cp .env.example .env
   ```

3. **Run the development server**:
   ```bash
   pnpm dev
   ```

4. **Build for production**:
   ```bash
   pnpm build
   ```

## Design Philosophy
"Financial Noir" - A sophisticated dark theme using a palette of deep charcoal, gold, and emerald. It emphasizes clarity, precision, and a premium feel, avoiding generic AI-generated aesthetics.
