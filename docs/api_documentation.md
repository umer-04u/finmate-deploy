# FINMATE: API Documentation

This document explicitly defines the RESTful endpoints provided by the backend FastAPI server. The frontend utilizes these endpoints via the Axios HTTP client.

## Base URL
`http://localhost:8000` (Local Development)

---

## 1. Upload Transactions (CSV)

**Endpoint:** `/api/transactions/upload`
**Method:** `POST`
**Summary:** Accepts a `.csv` bank statement, parses the data, applies categorization, detects anomalies, and generates forecasts.

### Request Body (multipart/form-data)
| Key  | Type | Description |
|---|---|---|
| `file` | File (`text/csv`) | The raw CSV bank export. Must contain at least Date, Description, and Amount columns. |

### Response (`200 OK`)
Returns the structured data, categorized transactions, and identified anomalies in JSON format.

```json
{
  "status": "success",
  "message": "Processed 124 transactions.",
  "data": {
    "transactions": [
      {
        "id": "abc-123",
        "date": "2023-06-15",
        "original_description": "UBER *EATS PENDING",
        "amount": 24.50,
        "type": "debit",
        "category": "Food & Dining",
        "is_anomaly": false,
        "anomaly_reason": null
      },
      ...
    ],
    "summary": {
      "total_income": 4500.00,
      "total_expenses": 3200.50,
      "savings_rate": "28.8%",
      "anomalies_detected": 3
    }
  }
}
```

## 2. Get Dashboard Analytics

**Endpoint:** `/api/analytics/dashboard`
**Method:** `GET`
**Summary:** Retrieves the high-level chart data required to populate the UI representations, categorized spend totals, and the 6-month historical/future trend.

### Response (`200 OK`)

```json
{
  "status": "success",
  "category_breakdown": {
    "Housing": 1200.00,
    "Food & Dining": 450.00,
    "Transportation": 120.00,
    ...
  },
  "monthly_trend": [
    {"month": "Jan", "spent": 3100.00},
    {"month": "Feb", "spent": 3050.00},
    {"month": "Mar", "spent": 3200.00}
    ...
  ],
  "forecast": {
    "next_month": "Apr",
    "predicted_spend": 3180.50,
    "insight": "Your expenditure is predicted to drop slightly due to reduced historical travel expenses in April."
  }
}
```

---

## 3. Get Specific Insights & Anomalies

**Endpoint:** `/api/analytics/insights`
**Method:** `GET`
**Summary:** Returns a list of all transactions marked as 'anomaly' by the Isolation Forest model, along with the human-readable explanation generated by the NLP post-processor.

### Response (`200 OK`)

```json
{
    "status": "success",
    "anomalies": [
        {
            "transaction_id": "xyz-987",
            "date": "2023-06-03",
            "description": "CITY POWER *BILL",
            "amount": 345.00,
            "category": "Utilities",
            "reasoning": "This transaction magnitude is 2.5 standard deviations above your historical utility moving average. This suggests a seasonal spike in summer power utilization."
        }
    ]
}
```

---

## 4. Error Responses

Standard HTTP error codes and descriptive JSON responses are returned in case of errors.

**`400 Bad Request`**: Malformed CSV, missing columns, or invalid data types.
```json
{
  "detail": "CSV must contain columns representing 'Date', 'Description', and 'Amount'."
}
```

**`422 Unprocessable Entity`**: Invalid parameter types.

**`500 Internal Server Error`**: Failures in the ML execution pipeline.
